# 计算机软件著作权登记申请表官方字段填报模板

> 适用平台：[中国版权保护中心微平台 / 在线业务系统](https://register.ccopyright.com.cn/)

---

## 一、 软件基本信息

| 字段名称 | 推荐填报规范 | 审核注意事项 |
| :--- | :--- | :--- |
| **软件全称** | `{{APP_NAME}}` | 必须以「软件/系统/平台/工具」结尾，如 `XXX管理系统` |
| **软件简称** | `{{SHORT_NAME}}` | 须与应用商店 App 名称一致 |
| **版本号** | `{{VERSION}}` | 必须以大写英文字母 V 开头，如 `V1.0` |
| **著作权人全称** | `{{COMPANY_NAME}}` | 必须与营业执照公章完全一致 |
| **企业类别** | `企业法人` | 个人申报则填 `自然人` |
| **权利取得方式** | `原始取得` | 自研项目选原始取得 |
| **权利范围** | `全部权利` | 选全部权利 |
| **软件分类** | `应用软件` -> `相应业务二级分类` | 避免选择涉及金融牌照/信贷/支付类高危类目 |
| **开发完成日期** | `{{COMPLETE_DATE}}` | 必须早于或等于首次公开发表日期 |
| **发表状态** | `未发表` (或 `已发表`) | 首次申报建议选「未发表」 |
| **开发硬件环境** | `PC 兼容机 / Mac 系列计算机，CPU 8核以上，内存 16GB` | 常规开发工作站配置 |
| **运行硬件环境** | `主流智能移动终端 / Linux 云服务器` | 对应项目实际部署终端 |
| **开发语言与环境** | `{{PROGRAMMING_LANGUAGES}}` | 真实技术栈，如 `TypeScript, Vue 3, Python 3.12` |
| **运行支持软件** | `Android / iOS 操作系统，Python 3.12+，Node.js 20+` | 宿主依赖 |
| **源程序量 (代码行数)** | `{{CODE_LINES}}` 行 | 填写大致总行数 (如 25,000) |
